# Parsing contract

lines(source) accepts any finite iterable of strings, including a one-shot generator. Return each line stripped of surrounding ASCII spaces, tabs, CR, and LF, omitting empty results and preserving duplicates and order. Consume the iterable at most once. Do not require a list or array.

All input values must remain unchanged. Record fields are scalar values unless stated otherwise. Numeric inputs and results are JavaScript safe integers unless represented as decimal text.

Run `python3 test.py` in this directory. No packages or installation are needed.
