# Allocation contract

coins(amount, denominations) returns the smallest number of coins that sum to amount. amount is an integer from zero through 200. Denominations are distinct positive integers and always include 1. Any number of each coin is available. The denomination system need not be canonical. Do not mutate denominations.

All input values must remain unchanged. Record fields are scalar values unless stated otherwise. Numeric inputs and results are JavaScript safe integers unless represented as decimal text.

Run `node test.mjs` in this directory. No packages or installation are needed.
