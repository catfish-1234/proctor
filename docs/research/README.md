# Proctor research package

Decision snapshot: 2026-10-16. **Main-track ambition: selective protection of
evolving verification (PR #47 framing 2), evaluated through a policy-conditioned
benchmark (framing 1).** Framing 3 supplies failure attribution. This is a research
design, not a result or completed prevention system.

Start with [PLAYBOOK.md](PLAYBOOK.md), a self-contained sequence for a student:
commands, data collection, infrastructure to build, budgets, timeline and stop gates.
The supporting documents are:

- [Paper plan](positioning.md): thesis, proposed contributions and threat model.
- [Experimental protocol](evaluation-plan.md): baselines, trials, metrics and statistics.
- [Dataset design](dataset-design.md): independent sources, provenance and labels.
- [Related work](related-work.md): verified primary sources and novelty boundaries.
- [Venues and timeline](venues-and-timeline.md): official deadline checks and realistic fit.
- [Taxonomy](taxonomy.md): surfaces and current detector coverage from PR #47.
- [Seed replay](seed/README.md): preserved 24- and 48-case synthetic development artifacts.
- [Validation history](validation.md): measured checks, distinct from planned research.

All new experimental numbers are planned. Existing seed measurements stay in their
original reports and never become independent, real-agent or prevention evidence.
No detector changes, live research execution, submission, release or announcement
are part of this docs revision. Stronger claims depend on the protocol's evidence
gates; a workshop remains a fallback rather than the default target.
